## O que eu faço

- **Desenvolvimento Frontend**: aplicações web com React, Next.js e TypeScript, de fluxos com formulários complexos a painéis administrativos
- **Liderança Técnica**: decisões de arquitetura de frontend, code review, definição de padrões e apoio a outros desenvolvedores
- **Migração de Legado**: manutenção de sistemas em Vue 2 (Vuex, Vuetify) e migração para Next.js
- **UI & Design System**: interfaces acessíveis e consistentes com Tailwind CSS, shadcn/ui e Radix UI
- **Estado & Integração com APIs**: Zustand, TanStack Query, tRPC, REST e comunicação em tempo real com Socket.io
- **Formulários & Validação**: React Hook Form e Zod
- **Testes Automatizados**: E2E com Playwright e Cypress, unitários e de integração com Jest, Vitest e Testing Library
- **Entrega Contínua**: pipelines de CI/CD, monitoramento de erros com Sentry e trabalho em times ágeis (Scrum)

### E no backend?
Criação de APIs REST com Node.js e Express, modelar um CRUD e persistir os dados em MongoDB ou MySQL. Isso me ajuda a conversar com o time de backend e a integrar o frontend com mais segurança.
